# Kopiur web UI — M3: the SPA (Vite + React + TanStack + React Flow)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ship the browser application that `kopiur-ui` serves — repositories and their replication topology, snapshots and the files inside them, policies, schedules, restores, maintenance, doctor — built from TypeScript types generated out of the Rust wire model, embedded into the binary by `rust-embed`.

**Architecture:** a Vite + React 19 single-page app under `crates/ui/web`, routed by TanStack Router, fetching through TanStack Query against the `/api/v1` surface built in M2. Every API type is generated by `cargo xtask gen-ui-types` from `kopiur_ui_model::export_all` (ts-rs) and checked in, so the SPA cannot drift from what the server serializes; `mise run gen-check` fails on drift. `mise run ui-build` writes `crates/ui/web/dist`, which `crates/ui/build.rs` stages into `$OUT_DIR/web` for `rust-embed`. A backend-only checkout still compiles: `build.rs` embeds a placeholder page unless `KOPIUR_UI_REQUIRE_WEB=1`.

**Tech stack:** Vite 7, React 19, TypeScript 5 (strict), TanStack Router + Query + Table, `@xyflow/react` + `elkjs` (lazy chunk, layout in a worker), vitest + testing-library, eslint 9 flat config, prettier, pnpm (pinned by mise).

## Global Constraints

- **Never hand-write an API type.** Everything the server sends or receives is generated into `crates/ui/web/src/api/types/` by `cargo xtask gen-ui-types`. A hand-declared interface mirroring a server shape is a defect, even if it compiles.
- **No `src/lib/` directory anywhere in the SPA.** The root `.gitignore` carries `lib/` from a Python template and would silently untrack it. Source lives under `src/{api,routes,components,util,charts}`.
- **`mise run test` stays node-free.** The Rust test task must not require pnpm or a `node_modules`. Frontend checks live in `ui-check` / `ui-build`.
- **CI runs individual mise tasks, not `mise run ci`.** Any new gate needs an explicit step in `.github/workflows/ci.yaml`.
- **`.mise/mise.lock`**: adding pnpm is the one deliberate lockfile change in this milestone; commit exactly that entry and nothing else. Any other lockfile churn from running a mise task is reverted with `git checkout .mise/mise.lock`.
- **Every enum switch uses `assertNever`** against the generated union (which includes `Unknown` variants). An unhandled variant must be a type error.
- **Every fetch goes through the generated client**; no bare `fetch()` in a component. Mutations send `X-Kopiur-Request: 1` and `Content-Type: application/json`; the server rejects them otherwise.
- **Errors are RFC 9457 problems.** The client detects `application/problem+json` and surfaces `what` / `why` / `fix` — never a bare status code, never `[object Object]`.
- **`cargo build -p kopiur-ui` must still succeed with no `web/dist`** (placeholder path) and must fail with `KOPIUR_UI_REQUIRE_WEB=1` and no bundle.
- Verification for every task: `mise run ui-check` and `mise run ui-build` green, plus `cargo test -p kopiur-ui --locked`. Grep logs for `FAILED`/`error` after stripping ANSI; never trust a truncated tail or a wrapper's exit code.

```

  pnpm-lock.yaml          committed
  vite.config.ts          /api proxy → :8090; manualChunks: topology; worker format es
  tsconfig.json           strict, noUncheckedIndexedAccess, exactOptionalPropertyTypes

  index.html
  src/
    main.tsx              router + query client bootstrap
    api/

    util/                 formatting (bytes, durations, timestamps), assertNever

```

`ts-rs` writes files itself rather than returning content, so the existing `Artifact` write/check machinery does not apply. The check compares a fresh export in a temp dir against the checked-in tree.

```rust
#[test]
fn a_missing_file_is_reported_as_drift() {
    let tmp = tempdir();
    std::fs::write(tmp.path().join("Problem.ts"), "export type Problem = {};\n").unwrap();
    let drift = compare_trees(tmp.path(), &empty_dir()).expect("compare");
    assert!(
        drift.iter().any(|d| d.contains("Problem.ts")),
        "a file present in the export and absent from the tree must be drift, got {drift:?}"
    );
}

#[test]
fn a_changed_file_is_reported_as_drift() { /* same shape, differing bytes */ }

#[test]
fn identical_trees_are_not_drift() { /* empty Vec */ }
```

- [ ] **Step 3: Implement `crates/xtask/src/ui_types.rs`**

```rust
//! `gen-ui-types` — export the `kopiur-ui-model` wire types to TypeScript.
//!
//! `ts-rs` writes the files itself, so this subcommand exports into a scratch
//! directory and then either syncs it into the tree (`gen`) or reports the
//! difference (`--check`). One source of truth: the Rust types.

/// Directory the SPA's generated types live in, relative to the repo root.
pub const UI_TYPES_DIR: &str = "crates/ui/web/src/api/types";

/// Compare an exported tree against the checked-in one, returning one
/// human-readable line per difference (missing, extra, or changed file).
pub fn compare_trees(exported: &Path, checked_in: &Path) -> Result<Vec<String>>;

/// Export into a temp dir, then write or check.
pub fn run(check: bool) -> Result<()>;
```

Rules: the export goes to a temp dir under `target/`; `run(false)` mirrors it into `UI_TYPES_DIR`, **deleting files the export no longer produces** (a stale type is drift too); `run(true)` returns an error listing every difference with the fix hint `run \`mise run gen\``.

## Risks

| Risk | Mitigation |
|---|---|
| ts-rs output does not match what serde actually writes (renames, `Option`, generics) | the generated types are the only source; a vitest compiles a real fixture captured from the server against them. If a mismatch appears, fix the Rust type, never the TypeScript. |
| elkjs bundle weight | lazy route chunk + worker; size measured and recorded in Task 4. |
| pnpm pin drifts from CI | `--frozen-lockfile` everywhere; `mise install --locked` in CI needs the committed lock entry. |
| A generated file gets hand-edited | `ui-check` ends with `git diff --exit-code` over the generated directory. |
| The SPA grows a hand-written API type by accident | eslint rule + review; the `api/types` directory is the only place types may be declared. |
