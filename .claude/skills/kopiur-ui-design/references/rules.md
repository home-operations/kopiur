# Rules

Behaviour the look must never break. These were carried forward from the
previous design system; the redesign changed how things look, not these. Each
rule names what enforces it today, or is marked **new ratchet** — a test that does
not exist yet and should be added when the SPA adopts this system.

| #   | Rule                                                                                                                                                                                                                                                                            | Enforced by                                                                                                                                                                                             |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **Status is never colour alone.** Every state is a `.health[data-health]` pill with an icon and a word, a loud absence, or an icon beside one. No coloured dots, rows or borders that carry state alone (the overview status bar is `aria-hidden` decoration beside its words). | `src/styles.health.test.ts` (health colour only on lamps/icons/listed loud text); `HealthBadge.test.tsx` (distinct icon per state)                                                                      |
| 2   | **Kind colour and status colour never stand in for each other.** `--kind-*` appears only on stripes, kind chips and kind names; `--health-*` never marks a kind.                                                                                                                | **new ratchet** — extend `styles.health.test.ts` to fail when a `--kind-*` token is used outside `[data-kind]`, `.kind-*`, `.has-stripe`, and when a `--health-*` token appears in a `[data-kind]` rule |
| 3   | **Unknown never reads as healthy.** An unrecognised phase shows its raw word on the unknown pill; a verdict is never healthy while any source is loading or refused, or the scope is empty.                                                                                     | `components/verdict.test.ts`; `HealthBadge.test.tsx` (unknown → unknown); eslint `switch-exhaustiveness-check`                                                                                          |
| 4   | **Absence is worded.** "never …" is loud, _not reported_ is faint italic with its reason, `—` is not-applicable; a blank or a bare `0` is never an absence.                                                                                                                     | `components/unwired.test.tsx`; `SnapshotDetail` / `RepositoryTable` tests asserting the loud and unreported cells                                                                                       |
| 5   | **Every chart and graph has a spoken twin** (a table under a chart; buttons, a drawer and an edge list for the topology board; words beside the overview status bar).                                                                                                           | chart and topology component tests (`.chart__plot` + table, hidden edge list)                                                                                                                           |
| 6   | **Forbidden actions stay visible with their reason.** `aria-disabled`, focusable, reason on `aria-describedby` and on screen; "not permitted" (`disabledReason`) and "answer first" (`blockedReason`) are different.                                                            | `ActionButton.test.tsx`, `actions/ActionPanel.test.tsx`; route tests for short refusals (`routes/replications.test.tsx`, `routes/maintenance.test.tsx`)                                                 |
| 7   | **Data-costly choices are asked, never defaulted** (`pin`, `overwrite`): no radio starts selected; confirm is blocked until answered.                                                                                                                                           | `actions/SnapshotNowDialog.test.tsx`, `actions/RestoreDialog.test.tsx`. **new ratchet**: `SnapshotActions` still uses a pre-cleared pin checkbox — fold it into the radio choice                        |
| 8   | **Errors render the server's what / why / fix**, fix set apart; a 403 says it's RBAC and offers no retry.                                                                                                                                                                       | `ProblemBanner.test.tsx`, `ErrorState.test.tsx` (`[data-state="not-permitted"]`, no retry)                                                                                                              |
| 9   | **Skeletons, never spinners.**                                                                                                                                                                                                                                                  | `routes/index.test.tsx`, `ErrorState.test.tsx` (no `.spinner`)                                                                                                                                          |
| 10  | **Visible focus everywhere** (`--focus-ring`); a later `box-shadow` must not eat it.                                                                                                                                                                                            | `src/styles.focus.test.ts`                                                                                                                                                                              |
| 11  | **Contrast:** every token pair meets WCAG AA (4.5:1 text, 3:1 UI) in both themes.                                                                                                                                                                                               | `scripts/check-contrast.py` in this skill. **new ratchet**: run it from `ui-check`                                                                                                                      |
| 12  | **`light-dark()` only takes colours; shadows are not `light-dark()`.**                                                                                                                                                                                                          | `src/styles.focus.test.ts`                                                                                                                                                                              |
| 13  | **Reduced motion is honoured** (all transitions/animations collapse).                                                                                                                                                                                                           | `styles.css` `prefers-reduced-motion` block                                                                                                                                                             |
| 14  | **Monospace only for things you copy** — names, namespaces, paths, crons, users, ids. Never as decoration.                                                                                                                                                                      | review                                                                                                                                                                                                  |
| 15  | **CLI/CRD vocabulary only.** Kind names are written as the CRD kind; field names as the wire/CRD field. No invented words for operator concepts.                                                                                                                                | review                                                                                                                                                                                                  |
| 16  | **No API shape is hand-written in TypeScript.** Components read the ts-rs types from `src/api/types`.                                                                                                                                                                           | `mise run ui-check` drift gate                                                                                                                                                                          |
| 17  | **Bundle budget:** entry ≤ 480,000 B raw, any chunk ≤ 1,600,000 B. No web fonts (system stack).                                                                                                                                                                                 | `scripts/check-bundle-size.mjs` in `pnpm build`                                                                                                                                                         |

When a rule and a mockup disagree, the rule wins and the mockup is wrong.
