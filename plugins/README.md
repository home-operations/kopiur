# Krew index

This directory makes the kopiur repository double as a [krew custom
index](https://krew.sigs.k8s.io/docs/developer-guide/custom-indexes/):

```console
$ kubectl krew index add kopiur https://github.com/home-operations/kopiur.git
$ kubectl krew install kopiur/kopiur
```

`kopiur.yaml` is GENERATED by GoReleaser (the `krews:` block in
`.goreleaser.yaml`) and committed here by the release bot on every release —
do not edit it by hand. The bot pushes straight to `main`, so its GitHub App
must be a bypass actor on the `main` ruleset; without that the push is
rejected and krew users stay on the last manifest that landed.
